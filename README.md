# Open-ERP-Downloads
Public Windows installer downloads and release notes for Open ERP. Application source is maintained separately.

## Label and tag support files

[Download Open-ERP-Label-and-Tag-Support-Files.zip](support-files/Open-ERP-Label-and-Tag-Support-Files.zip)

Contains Brother P-touch Editor layouts for Open ERP packing and material labels
(QL-800, 62 mm continuous tape), plus STEP models for 3D-printable trade size 3 tags
with single or double holes. Print a test label to confirm fit and printer settings.
